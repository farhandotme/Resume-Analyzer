# =============================================================================
# ai_backend/requirements.txt
# Pinned & trimmed to ONLY what the code actually imports (verified against
# main.py, routes/, services/, config/, prompts/).
#
# Removed vs. the old pyproject.toml (unused by the code, was slowing every
# install and bloating the image): chromadb, langchain (top-level meta pkg),
# langchain-google-genai, langchain-openai, openai, pypdf.
# -> The app uses Qdrant (not Chroma) and Mistral (not OpenAI/Gemini), and
#    PyMuPDF (not pypdf) for PDF parsing.
#
# NOTE ON TORCH: sentence-transformers (used by langchain-huggingface for
# embeddings) depends on torch. Do NOT `pip install -r requirements.txt`
# blindly on a fresh image — install CPU-only torch FIRST (see Dockerfile),
# or pip will pull the full CUDA/NVIDIA GPU stack (multiple GB of unused
# downloads on a normal server with no GPU). This is almost certainly why
# your installs have felt slow.
# =============================================================================
